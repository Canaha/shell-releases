# Shell releases

Release files for **Shell**, a social space for desktop and VR where the worlds,
avatars and props are made by its players.

**Shell has not launched yet, and there is nothing to download here.**

## What this repository is for

The Shell launcher will download game updates from here automatically, so you
won't need to download anything from this page yourself. When Shell launches, the
place to get it will be linked here.

This repository holds release files only. It does not contain the game's source.

## Is it safe?

Every update will be signed. The launcher checks that signature and refuses
anything that doesn't match, wherever the files came from. Only get Shell from the
link above once it's published, not from re-uploads elsewhere.
